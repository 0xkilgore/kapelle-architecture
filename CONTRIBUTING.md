# Contributing

Useful contributions include reproducible reference bugs, clearer architectural explanations, synthetic failure cases, and proposals for portable orchestration contracts.

Start with [AGENTS.md](AGENTS.md) and [current status](docs/status.md). Run `npm test`, `npm run demo`, and `npm run walkthrough` with Node.js 20+. There is no package installation step or model account required for these commands.

For code changes, include a focused test for the behavior being changed. For documentation, check relative links and distinguish implemented behavior from proposals. Explain the user problem and the evidence for your change in the pull request.

Only contribute material you have permission to submit under the repository's MIT license. Preserve applicable notices on third-party material. Do not submit private deployment data or real personal records. Follow [SECURITY.md](SECURITY.md) for security reporting.
